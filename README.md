Distilled from the most popular products on [There's An AI For That](https://theresanaiforthat.com/leaderboard/) (2026 leaderboard + the long-running tools the directory is known for).

Machine catalog in the live app: `/llms.txt`, `/api/tools.json`, `/sitemap.xml`. Traction: `/traction`. Launch copy: `/launch`.

## Why pages, not a chatbot

Suites bury the job. A person (or an answer engine) looking for “rewrite this email” should land on `/tools/rewrite-email`, not a blank chat.

Each page is:

- **Agentic** — finishes the artifact; does not chat
- **LLM-friendly** — listed in `/llms.txt` and `/api/tools.json`
- **SEO** — unique title, definition, HowTo + FAQ schema, sitemap
- **AEO** — first paragraph is the answer; short FAQs models can cite
